## 2026-10-02
- **Phase 3.5 batch 3 — per-device behavior profiles (quiet-first: know what's normal, only shout when a device acts unlike itself).** The monitor now learns each device's habits: a `device_profiles` table stores per-MAC, per-hour baselines (average bytes moved and average outside contacts per local hour) learned from 14 days of flows, attributed to hardware addresses via ARP sightings and rebuilt lazily when stale (>6h).
