# ADR 002 — Whole-network mode via ARP-spoof relay

Date: 2026-10-01
Status: Accepted

## Context
brutedash started as a single-box SSH brute-force detector. The product vision is a
small-business network security system — one box covering the whole LAN, no per-seat
pricing, no MSP middleman.

## Decision
`NETMON_WHOLE_NETWORK=1` puts every detection rule on every LAN device via bettercap
ARP-spoof relay (`netmon/wifimon.cap`; per-machine caplets generated by `netmon/relay.py`).
This box becomes the LAN relay: all device traffic passes through it, so the detector
sees everything with per-device labels. The ARP-spoof detector flags our own spoofing
as a live self-test.

## Consequences
- The PC must stay awake and plugged in, or the LAN loses internet (documented in
  `docs/run-as-service.md`).
- Devices behind the Orbi subnet appear as the Orbi IP (known limitation).
- Related: ADR 001 (quarantine uses the same ARP mechanism, but approval-gated).
